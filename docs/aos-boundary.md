# Codex Token Monitor 与 AOS 的边界

Codex Token Monitor 只负责 Codex 当前工作状态、安全数字用量、额度、数据源健康、工作流风险、近期任务、诊断、桌面组件和本产品设置。AOS 负责知识库、项目记忆、Context Builder、项目资料整理、知识导入导出、跨设备迁移、基于项目记忆生成新线程上下文及跨模型长期记忆。

## 本阶段明确不做

- 不创建知识库、项目记忆或项目上下文；
- 不保存项目正文、Prompt、Response、消息、工具输出或 Reasoning 正文；
- 不扫描用户项目文件；
- 不生成基于项目内容的交接摘要；
- 不导入、导出或迁移项目知识；
- 不实现 AOS 式上下文恢复；
- 不声明能够恢复用户项目工作状态；
- 不新增 AOS 运行依赖，也不修改 AOS 仓库。

## “准备新线程”

该操作只根据安全数字解释为什么建议切换，展示通用步骤，打开 Codex，并复制一个需要用户手工填写的通用模板：

> 请继续处理当前任务。下面是我手动整理的任务目标、已完成内容、当前状态和下一步：【请在这里粘贴或填写内容】

模板不自动填入标题、Prompt、Response、项目路径、文件列表或任何项目内容。界面明确提示：未来安装 AOS 后可由 AOS 提供项目上下文；当前版本不会读取项目内容。本阶段没有 AOS 接口、进程通信或可选依赖。
