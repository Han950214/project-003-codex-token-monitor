# Codex Token Monitor 与 AOS 的边界

Codex Token Monitor 只负责 Codex 当前工作状态、安全数字用量、额度、数据源状态、近期会话、桌面组件和本产品设置。AOS 负责知识库、项目记忆、Context Builder、项目资料整理、知识导入导出、跨设备迁移、基于项目记忆生成上下文及跨模型长期记忆。

## 本阶段明确不做

- 不创建知识库、项目记忆或项目上下文；
- 不保存项目正文、Prompt、Response、消息、工具输出或 Reasoning 正文；
- 不扫描用户项目文件；
- 不生成基于项目内容的交接摘要；
- 不导入、导出或迁移项目知识；
- 不实现 AOS 式上下文恢复；
- 不声明能够恢复用户项目工作状态；
- 不新增 AOS 运行依赖，也不修改 AOS 仓库。

当前版本没有 AOS 接口、进程通信或可选依赖，也不提供项目上下文生成入口。
