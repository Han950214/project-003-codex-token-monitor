# 桌面迷你组件

## 行为

用户最小化主状态中心，或点击主界面的组件按钮后，主窗口会隐藏，并显示一个单进程 `CTkToplevel` 组件。组件默认处于 `compact` 收起状态，可点击箭头切换为 `expanded` 展开状态；这是同一桌面组件的两种显示状态，不是主界面模式。两种布局在同一个窗口内切换，不创建第二个 root、`mainloop` 或数据读取路径。组件默认位于主窗口所在显示器的工作区右上角，保留 16 px 边距并避开任务栏；Windows 工作区 API 不可用时回退到 Tk 主屏幕尺寸。

组件默认置顶，并以用户设置的不透明度显示；鼠标进入后恢复为 100%，离开短延迟后恢复闲置值。组件可拖动；位置仅以安全 x/y 坐标保存在 UI settings 中，失效时回退右上角。双击组件会隐藏组件并恢复状态中心。展开、收起、拖动、透明度变化和恢复都只复用共享 presentation，不查询 Rollout、SQLite、标题或额度。

点击主窗口关闭按钮时，会显示“最小化到任务栏 / 退出应用”选择框；当天记住的主窗口动作可直接执行。迷你组件的关闭按钮属于显式退出路径，即使当天已记住“最小化”，仍会再次显示同一选择框。任务栏最小化与隐藏到托盘仍由主界面和系统托盘提供，两者恢复都不重新查询数据。勾选“今天不再提示”后，仅在本机 UI settings 中保存当天日期与所选动作；次日自动恢复询问，不保存任何账号或认证信息。

## 两种显示状态

### compact（默认）

- 状态图标与最高优先级状态；
- 5 小时额度可靠剩余比例，未知时为 `—`；
- 展开箭头。

### expanded

- 当前状态与选中 Thread 的安全短标题；标题固定为单行省略，完整标题通过 Tooltip 查看，不会挤压相邻指标；
- 轮次、本轮用量、会话累计；两项用量范围独立且不互相回填，未知时显示 `—`；
- 5 小时额度的可靠剩余比例与重置时间；
- 打开主界面、手动刷新、更多工具、收起和关闭。“更多工具”会恢复状态中心并直接打开工具页，不是未实现的弹出菜单。

大数字使用紧凑格式，完整数值可通过 Tooltip 访问。状态文字与图标共享绿色、橙色、红色或灰色语义色；5 小时剩余额度在可靠且充足时为绿色，较低或陈旧时为橙色，无效时为红色，未知时为灰色。设置中的 `widget_mode=compact / expanded` 只决定组件默认显示状态；旧 `dashboard_mode` 配置会被安全忽略，界面不提供对应设置。

自动跟随模式会在最小化瞬间解析为具体 Thread。组件期间只刷新该 Thread；其他 Thread 的新事件不会触发跳转。固定 Thread 跌出 500 条近期候选后，仍使用已知 Rollout 路径读取。没有可用选择时显示“暂无选中线程”和 `—`，不会选择其他 Thread 冒充。

百分比默认表示“已使用”。内部值为 `float | None`，范围钳制到 0–100；NaN、Infinity 和 used/remaining 不一致会标记为异常。未知值保持 `None`，UI 显示 `—`。重置时间内部使用带时区的 `datetime`，显示时转换到用户本地时区。

## 额度来源与安全边界

额度来源是本机已安装 Codex 提供的官方结构化 `app-server` 方法 `account/rateLimits/read`。Provider 只接收以下安全字段：

- `windowDurationMins`
- `usedPercent`
- `resetsAt`

`300` 分钟映射到 5 小时窗口，`10080` 分钟映射到每周窗口。窗口时长不明确时不会猜测映射。来源响应由 Codex 自己处理认证；本项目不读取、保存或输出 Cookie、Access Token、Refresh Token、Authorization Header、API Key 或 Session Secret，也不打印原始响应。

本项目仍不读取 prompt、response、preview、user/assistant message、tool output 或 reasoning 正文，不扫描项目文件，也不生成项目上下文。额度 DTO 不包含凭据字段，也不创建持久化额度快照。刷新失败时仅保留进程内上一份数据并标记为陈旧；桌面组件不依赖也不替代 AOS。

## 当前不包含

系统托盘、开机启动和默认启动模式见 [Windows 托盘和启动设置](windows-tray-and-startup.md)。自动更新、额度预测、Credits、账户切换、多账户合并和云端同步仍不在当前范围内。
