# 桌面迷你组件

## 行为

主窗口最小化或用户点击组件按钮后，应用隐藏主窗口并显示同进程的 `CTkToplevel`。组件默认位于当前显示器工作区右上角，保持 16 px 边距并避开任务栏；Windows 工作区 API 不可用时回退到 Tk 屏幕尺寸。

组件默认置顶并使用用户配置的闲置透明度；鼠标进入恢复为 100%，离开后恢复闲置值。展开、收起、拖动、透明度变化和恢复主窗口只复用共享 presentation，不查询 Rollout、SQLite、标题或额度。

## 两种显示状态

### compact

- 事实状态与状态颜色；
- 5 小时额度的可靠剩余比例，未知时显示 `—`；
- 展开按钮。

### expanded

- 事实状态与所选会话的安全标题；
- 轮次、当前响应用量、会话累计；
- 5 小时额度的可靠剩余比例与重置时间；
- 恢复主界面、手动刷新、收起和退出。

长标题单行省略，完整安全标题通过 Tooltip 查看。状态只反映当前数据是否完成、进行中、部分、不可用或未选择，不生成操作建议。

## 选择与关闭

自动跟随模式在最小化瞬间解析为具体会话，组件期间只刷新该会话。没有可用选择时显示“暂无选中会话”和 `—`，不会用其他会话代替。

组件关闭按钮是显式退出路径；主窗口关闭行为仍由用户的“最小化到任务栏 / 退出应用”设置决定。系统托盘可恢复主窗口、显示组件、隐藏窗口、刷新、切换自动刷新、打开设置或退出。

## 额度与隐私

额度来自本机 Codex `app-server` 的结构化只读方法 `account/rateLimits/read`。本项目不读取、保存或输出 Cookie、Access Token、Refresh Token、Authorization Header、API Key 或 Session Secret，也不读取 Prompt、Response、消息、Tool Output 或 Reasoning 正文。
