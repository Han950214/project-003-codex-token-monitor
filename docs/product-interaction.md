# Phase 3.0-UI-Final 产品交互

## Phase 3.1-D 用量重点

“用量趋势 / Usage Trends”在既有已观测用量范围下增加“用量重点 / Usage insights”卡片。范围切换继续只触发同一条后台只读历史查询；卡片消费 Phase 3.1-C 规范响应归并同时生成的结果，不直接访问 SQLite，也不在 Tk 主线程排序或去重。

卡片依次展示高消耗会话、高消耗响应和低缓存复用会话。前两组默认三项，可由用户在当前页面本地展开到五项；低缓存复用固定三项。展开不会读取数据。行内只显示按需延长的安全短标签、Token 数字或加权缓存复用率，不显示完整 Thread ID、完整响应安全身份、Prompt、标题、项目名、路径或正文。

完整、有限、部分、无观测与不可用状态沿用已观测用量的覆盖和新鲜度语义；待加载或不可用时会清空旧排名，避免把上一范围的结果误认为当前结果。缓存复用只纳入同时具有有效 Input、Cached 且 Input 大于零的响应；旧 v3 身份未知 Token 行不进入排名。

Codex Token Monitor 的当前定位是“Codex 工作流状态助手”，不是要求普通用户研究 Token 字段的数据面板。首次启动会自动检测 Codex、读取安全数字、选择最近活动 Thread、获取额度并生成一个最高优先级建议；失败时在统一状态中心显示“连接异常 / 一键诊断”。

## 应用外壳与信息架构

主窗口只有四个一级入口：状态中心、历史记录、工具、设置。左下角只显示数据连接状态和版本，不显示主界面模式。顶部栏保持单行，提供整体状态、自动刷新状态、手动刷新、桌面组件、设置和语言入口。

当前任务不是一级导航，而是二级详情。用户可以从状态中心的当前任务卡、最近任务、历史记录选择或 Advisor 的“查看当前任务”操作进入，并可返回状态中心。导航和详情页切换只改变可见 Frame，不调用 Rollout、SQLite、标题或额度接口。

## 单一状态中心

状态中心固定包含七个区域，并复用同一份 snapshot、presentation、Advisor 结果、quota snapshot 和本地历史汇总 DTO：

1. 当前状态与智能建议：只显示最高优先级 Advisor、最多两行原因、一个突出主操作和一个弱样式次操作；Advisor 规则仍集中在独立规则模块中。
2. 核心指标：“当前指令 / Current response”表示最新一条已观测响应；“当前会话 / Current session”表示当前 Thread 权威累计数字。Input、Output、Total、Cached、Reasoning 等完整安全数字在当前任务详情中按需查看。
3. 已观测用量：按今日、最近 5 小时、最近 7 天和最近 30 天汇总本机保存的规范响应观测，显示 Total、Input、Output、Cached、Reasoning、响应数、会话数、平均每条响应与缓存复用，并明确覆盖范围和新鲜度。无历史时显示 `—` 和“暂无已观测数据”，不显示误导性零值。
4. 当前任务：显示官方 `Thread.name` 或安全回退标题、状态、轮次、当前指令、当前会话和最近活动；长标题省略但完整标题可访问。
5. 官方额度状态：独立显示 5 小时与每周额度的已使用比例、剩余比例和可靠重置时间；未知值为 `—`，陈旧值明确标记，不预测可用时长，也不与本地 Token 相互换算。
6. 快捷操作：只显示一键诊断、打开 Codex、查看历史、更多工具四项。
7. 最近任务：默认显示最近 5 条，点击整行后使用完整刷新留下的进程内 snapshot 直接切换当前任务，并同步指标、Advisor 和历史选择；“查看全部任务”进入历史记录页。

宽窗口使用两列三行主布局；中等宽度按区域自动换列；窄窗口使用单列和垂直滚动，不提供水平滚动。Resize 只调整布局，不读取数据，也不丢失当前 Thread、历史页码、筛选或自动刷新状态。

## 当前任务详情与历史记录

当前任务详情展示完整安全标题、状态、最近活动、轮次、Input、Output、Total、Cached、Reasoning、Cache Hit、会话累计、额度与 Advisor，并提供切换任务、准备新线程、手动刷新和返回状态中心。页面进入和内存任务切换不读取数据，只有手动刷新进入真实刷新路径。

历史记录页负责完整任务列表，保留 7/30/90 天、状态筛选、每页 10 条、上一页/下一页、页码、总条数、选中高亮、固定选择、自动跟随和内存快速切换。状态中心不复制分页功能，也不根据标题文字推断任务类型。

## 设置与桌面组件

设置页不提供主界面模式选项。旧配置中的 `dashboard_mode` 可被读取但会安全忽略，不影响其他设置；`widget_mode=compact / expanded` 继续表示桌面组件的收起/展开显示状态，不是两套主界面。

## 数据访问合同

- 允许访问真实数据：首次自动刷新、手动刷新、固定 60 秒自动刷新、一键诊断。
- 不访问真实数据：导航、语言、页面切换、组件展开/收起、恢复窗口、设置保存、历史页内翻页和缓存选择。
- 历史范围切换只在线程外查询 Token Monitor 自有 SQLite，不刷新 Rollout、标题或额度，也不写历史。
- UI 页面不直接访问 SQLite 或 Rollout；`DashboardViewModel`、历史 Repository/聚合服务与诊断服务分别提供共享刷新、窗口汇总和只读检查路径。
- 进程只有一个 Tk root 和一个 `mainloop`；桌面组件与对话框均为 `CTkToplevel`。

## 中英文

全部新增操作、建议、诊断状态和设置通过集中翻译键生成。内部状态代码和 DTO 字段保持英文，但不直接展示给普通用户。切换语言只重绘当前内存 presentation。

## 安全与 AOS 边界

Advisor、状态中心和详情页只使用既有安全数字、时间与结构化状态，不读取或保存 Prompt、Response、消息、Tool Output 或 Reasoning 正文，也不扫描项目文件。“准备新线程”只展示数字判断原因、打开 Codex 并复制不含项目内容的通用模板。本产品不创建知识库、项目记忆或项目上下文，不依赖也不替代 AOS。
