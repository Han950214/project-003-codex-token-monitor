# Token Monitor Desktop 视觉复核

使用真实应用和真实运行截图验证，不以代码截图、静态 mock 或未运行的断言替代现场证据。

## 准备

1. 确认当前阶段、Git 基线、现有用户改动和数据语义边界。
2. 使用项目现有启动或 smoke 命令运行真实 Desktop；优先复用已有 GUI acceptance、截图和测试工具。
3. 不修改系统 DPI；使用可控窗口几何、Tk 缩放配置或项目已有工具检查可实现范围内的 100%、125%、150% 兼容性。

## 检查矩阵

- 空数据、正常数据、数据源不可用、刷新中、自动刷新、错误和首次启动；
- 单条响应、当前线程累计、时间范围汇总、官方额度与本地统计是否不会互相误读；
- 来源、时间戳以及真实、估算、过期、未知状态是否清晰；
- 长数字、窗口缩放、文字截断、控件遮挡、滚动、焦点和 DPI；
- telemetry bar、Dashboard、设置、系统托盘和桌面组件是否共享一致状态；
- 有参考图时按同尺寸逐项比较布局、字体、卡片、颜色、间距和控件状态。

## 两轮闭环

至少完成两轮“实现 → 真实运行 → 截图 → 差异清单 → 修正 → 再次截图”。第二轮确认第一轮差异已关闭，并记录仍存在且可解释的技术限制。

无法自动启动或截图时，报告具体命令、错误和未验证项，不伪造结果。不得修改系统 DPI、安装软件或改变数据解析与口径。
